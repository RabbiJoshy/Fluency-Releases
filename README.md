# Fluency releases

Published release files for the Fluency app, served by GitHub Pages at
`https://rabbijoshy.github.io/Fluency-Releases/`. Kept out of the app's own
site so app deploys don't republish them.

Layout mirrors the app's `releases/` paths: `<language>/speech/<release-id>/…`
and `lyrics/<release-id>/…`. A release is immutable: publish a new release id
rather than editing one in place.
